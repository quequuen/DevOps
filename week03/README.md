## 3주차 정리

### Qwen / Ollama로 로컬 LLM 실행해보기
- Qwen
  - 질문에 답을 만들어내는 모델(LLM) 자체
- Ollama
  - 모델을 내 컴퓨터(로컬)에서 실행하고 관리해주는 서버 겸 CLI 도구
  - `ollama run qwen...` 형태로 Qwen 같은 모델을 내려받아 바로 실행해볼 수 있었음
  - 서버/클라이언트 구조를 눈으로 처음 체감한 실습 (Ollama가 서버, 내가 보낸 질문이 요청)

### 셸 스크립트 기초
- 여러 명령어를 하나의 파일에 적어두고 같은 절차를 반복 실행하는 것이 셸 스크립트
- 스크립트를 실행하려면
  - 첫 줄에 `#!/bin/bash` 같은 shebang으로 어떤 셸로 실행할지 지정
  - `chmod +x 파일명`으로 실행 권한을 줘야 `./파일명`으로 실행 가능
  - `cd "$(dirname "$0")"`로 스크립트 위치 기준 작업 경로를 고정해두면 어디서 실행하든 안전함
- 환경 변수(`USERNAME="홍길동"` 등)로 프로그램 실행 시의 설정값을 전달할 수 있음
- 명령은 끝나면 **종료 상태(exit code)** 를 남김
  - 0이면 성공, 0이 아니면 실패로 판단 (`echo $?`로 직전 명령의 종료 상태 확인)
- 표준 출력(정상 결과), 표준 오류(에러 메시지), 실패 종료(`exit 1`)를 구분해서 다루는 법을 배움
