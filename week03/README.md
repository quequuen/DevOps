## WEEK04 정리

- 명령어로 디렉터리 100개 만들기
```
for i in $(seq 1 100); do mkdir -p test/dir$i; done
```
	- seq: sequence(순서)의 줄임말. 즉, 1부터 100까지 반복.
	- $(...): Bash에게 괄호 안의 명령어를 먼저 실행하고, 그 결과를 여기다가 넣어달라는 의미. -> `for i in 1 2 3 4 5`를 말함.
	- `do`: 이제 다음 무언가를 한다고 정의하는 것.
		```
		for i in ...
		do
			TODO
		done
		```
	- `-p`: parent directories도 필요하면 같이 만들어 달라는 옵션. `mkdir -p test/dir1`을 실행했는데 `test`가 아직 없다면 일단 생성 후 `dir1`을 생성.

- `find . -type f -name "*.sh"`
	- `find .`: 현재 디렉터리(.)에서 시작해서 찾으라는 말.
	- `-type f`: file(일반 파일)인 것만
		- d: directory(디렉터리)
		- l: link(심볼릭 링크)
**현재 디렉터리에서 시작해서 하위 디렉터리까지 전부 탐색하면서, 일반 파일(`f`) 중 이름이 `.sh`로 끝나는 파일을 찾아라.

- `grep -R -n "exit 1" week03 2>/dev/null`
	- -R: Recursive(재귀적으로), week03 안에 있는 하위 디렉터리까지 전부 들어가서 찾음.
	- -n: 줄 번호 표시
	- week03: week03 디렉터리부터 시작해서 찾는 것. 만약 week03이 아닌 .이 있다면 현재 디렉터리부터 찾음. grep은 꼭 어디서부터 찾을지 지정을 해줘야 함. 	
- `grep -R "exit 1" week03 2>/dev/null | wc -l`
	- `|`: 왼쪽 명령어의 결과를 오른쪽 명령어에 넘겨두라는 의미. 파이프.
	- `wc -l`: word count, line count. 줄 수를 세라는 의미.
