### 서버와 가상화 개념
- 서버(Server)는 하드웨어(전원을 켜고 끄는 물리 장비)이자 동시에 소프트웨어(요청을 받아 응답하는 프로그램)라는 두 가지 의미를 함께 가짐
- 클라이언트가 **요청(Request)** 을 보내면 서버가 **응답(Response)** 하는 구조가 기본
- 서버를 운영하는 세 가지 방식
  - **베어메탈**: PC 한 대에 OS를 바로 설치해서 운영 (구조는 단순, 성능은 좋지만 한 대에 여러 용도를 섞어 쓰기 어려움)
  - **하이퍼바이저(VM)**: 하드웨어 위에 하이퍼바이저를 올리고, 그 위에 Guest OS를 여러 개 띄움 (격리는 강하지만 OS마다 자원을 따로 먹어 무거움)
  - **컨테이너**: Host OS(커널)를 공유하면서 애플리케이션 단위로만 격리 (가볍고 배포가 빠름 — 5주차 Docker에서 이어서 다룸)
- 즉, 가상화는 물리적으로 하나뿐인 컴퓨팅 환경 위에 논리적으로 여러 개의 환경을 만드는 기술이고, 컨테이너는 그중 서버 자원을 효율적으로 쓰기 위한 방식이라고 이해했다.

### 리눅스 실습 환경 구축
- WSL2 + Ubuntu로 윈도우에서도 리눅스 터미널 환경을 구성
- 터미널에서 파일/디렉터리를 다루는 기본 명령어 연습 (`ls`, `cd`, `mkdir`, `touch`, `cat` 등)

### 파일 만들고 확인하기 (실습)
```bash
$ echo "hello" > hello.txt
$ cat hello.txt
hello

$ cat > text.txt << 'EOF'
Hello, DevOps
Inhatc
EOF
$ cat text.txt
```
→ 결과물: [hello.txt](./hello.txt), [text.txt](./text.txt)

### Git / GitHub 기초
- `git init`, `git add`, `git commit`으로 로컬 저장소에 변경 이력을 남기는 법
- GitHub에 원격 저장소(이 저장소)를 만들고 `git remote add origin ...` → `git push`로 과제를 제출하는 흐름을 익힘
