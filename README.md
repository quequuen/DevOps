# DevOps

인하공업전문대학 컴퓨터정보공학과 DevOps 수업 실습 코드 저장소 (2026-2 / 감형렬 교수님)

## 강의 개요

소프트웨어를 개발하는 것과 운영하는 것 사이의 벽을 허무는 방법론인 DevOps를 배우는 과목으로, 작성한 코드가 실제 서버에서 동작하기까지의 전 과정을 직접 경험한다.

```
리눅스 → 버전관리 → 네트워크 → 컨테이너 → 오케스트레이션 → 자동화(CI/CD) → 모니터링
```

## 학습 목표

- 리눅스 명령어와 쉘 스크립트로 반복 작업 자동화
- Git 브랜치 및 Pull Request로 팀 단위 협업 수행
- 애플리케이션을 도커 이미지로 만들어 배포, 여러 컨테이너를 함께 운영
- Kubernetes(k8s)에 애플리케이션 배포·확장, 무중단 갱신, 장애 복구 수행
- GitHub Actions로 빌드·배포 파이프라인 자동화
- 팀 단위로 전체 파이프라인을 설계·구축하고 결과를 문서화, 발표

## 수업 운영 원칙

1. **그냥 하기** – 과도한 생각보다 작게 시작해서 피드백을 계속 받기
2. **실패해도 오케이** – 기록 → 가설 재설정 → 재도전
3. **질문은 언제나 환영** – 질문을 정리하면 사고도 정리됨
4. **교사의 위치** – 정답 전달이 아닌 방향 제시, 문제 설계, 피드백 제공

## 생성형 AI 사용 규정

과제에 생성형 AI 사용은 적극 권장되지만 다음을 지켜야 한다.

- 본인의 이해와 판단을 바탕으로 수정 및 활용할 것
- 주석 및 설명은 반드시 본인의 언어로 작성할 것
- 바이브/에이전틱 코딩은 본인이 구조를 이해하고 검증할 수 있을 때만 사용할 것
